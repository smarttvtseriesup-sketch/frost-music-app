# Music Sources and Licensing

## Demo

The app currently uses SoundHelix example MP3 URLs for UI and playback development. Those recordings are demonstration assets and must not be presented as FROST catalog content in a public commercial release.

## Production requirements

FROST must source music only through:

- Providers with explicit streaming rights
- Creative Commons recordings with compatible licenses
- Public-domain recordings
- Artist-uploaded music with distribution permission

The app must implement backend-only API credentials, licensing disclosures, artist attribution, and geographic/rightsholder restrictions supplied by the selected provider. It must not scrape or bypass Spotify, YouTube Music, or any other restricted platform.
